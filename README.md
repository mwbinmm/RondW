هر ۱۵ دقیقه صفحات مربوط به کدهای مختلف ۰۹۱۲ رو در سایت rond.ir چک می‌کنه
و اگه شماره‌ای زیر سقف قیمتِ تعیین‌شده پیدا بشه، با ربات تلگرام بهت خبر
می‌ده. هر شماره فقط یک‌بار اطلاع داده می‌شه.

## ⚠️ نکته‌ی مهم درباره‌ی محدودیت این ابزار

سایت rond.ir توی فایل `robots.txt`‌ش دسترسی خودکار به صفحه‌ی «جستجوی
پیشرفته» (`rond.ir/s?...`) رو مسدود کرده. این اسکریپت فقط از صفحات
«لندینگ» عمومی (`/SimLanding/...`) استفاده می‌کنه که اجازه‌ی دسترسی
خودکار دارن — ولی این صفحات فقط بخشی از کل آگهی‌های سایت رو نشون می‌دن،
نه همه‌شون. یعنی این ابزار **همه‌ی موارد رو تضمین نمی‌کنه**، ولی قانونیه
و همچنان بخشی از موارد مناسب رو پیدا می‌کنه. برای پوشش کامل، هر از گاهی
خودت هم از فرم جستجوی سایت به‌صورت دستی چک کن.

## مراحل راه‌اندازی از صفر

### ۱. ساخت ربات تلگرام
1. تو تلگرام برو به [@BotFather](https://t.me/BotFather)
2. بفرست `/newbot` و اسم دلخواه بده
3. یه **توکن** می‌گیری شبیه: `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxx`

### ۲. گرفتن Chat ID
1. برو به ربات تازه‌ساخته و یه پیام بده (مثلاً «سلام») — این مرحله حیاتیه، بدونش Chat ID پیدا نمی‌شه
2. تو مرورگر باز کن (بدون فاصله بین `bot` و توکن):
   `https://api.telegram.org/botTOKEN/getUpdates`
3. دنبال `"chat":{"id":` بگرد؛ عدد جلوش Chat ID توئه

### ۳. ساخت ریپازیتوری در گیت‌هاب
1. github.com → **+** → **New repository** → یه اسم بده → **Create repository**

### ۴. آپلود فایل‌ها
1. تو صفحه‌ی خالی ریپازیتوری، رو لینک **uploading an existing file** بزن
2. فایل‌های `rond_watcher.py`، `requirements.txt`، `state.json`، `README.md` رو آپلود کن
   **دقت کن:** اسم فایل پایتون باید دقیقاً `rond_watcher.py` باشه (با
   زیرخط `_`، نه فاصله) — بعضی گوشی‌ها موقع انتخاب فایل، فاصله رو با
   زیرخط عوض می‌کنن که مشکلی نیست، ولی برعکسش (زیرخط به فاصله) باعث خطا می‌شه.
3. **Commit changes**
4. دوباره **Add file → Create new file**، اسم فایل رو بنویس:
   `.github/workflows/watch.yml`
   محتواش رو پیست کن، **Commit changes**

### ۵. مجوز نوشتن برای Actions (خیلی مهم)
1. **Settings → Actions → General**
2. پایین صفحه بخش **Workflow permissions**
3. گزینه‌ی **Read and write permissions** رو انتخاب کن (نه گزینه‌ی Read-only) → **Save**

بدون این مرحله، اسکریپت نمی‌تونه فایل `state.json` رو آپدیت کنه و هر بار
همون شماره‌های قبلی رو دوباره اطلاع می‌ده.

### ۶. تنظیم Secrets
**Settings → Secrets and variables → Actions → New repository secret**
- `TELEGRAM_BOT_TOKEN` = توکن مرحله ۱
- `TELEGRAM_CHAT_ID` = عدد مرحله ۲

### ۷. تست
1. تب **Actions → Rond Watcher → Run workflow → Run workflow**
2. **فقط یک‌بار بزن و صبر کن** (زدن چندبارِ پشت‌سرهم باعث تداخل بین
   اجراها می‌شه) — بعد از چند ثانیه رفرش کن، باید ✅ سبز بشه

از این به بعد خودش هر ۱۵ دقیقه، بدون نیاز به کار دیگه‌ای، اجرا می‌شه.

## اگه یه روز باز خطا گرفتی

- **Failure تو مرحله‌ی "Run watcher"**: احتمالاً ساختار HTML سایت
  عوض شده؛ باید تابع `fetch_listings` در `rond_watcher.py` به‌روز بشه
- **Failure تو مرحله‌ی "Commit updated state"**: بخش ۵ (Workflow
  permissions) رو دوباره چک کن
- **چیزی تو تب Actions نمی‌آد**: مطمئن شو فایل دقیقاً تو مسیر
  `.github/workflows/watch.yml` هست (نه جای دیگه) و پسوندش `.yml` هست
